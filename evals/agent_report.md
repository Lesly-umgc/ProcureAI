## How to produce this report

```bash
cd /path/to/ProcureAI
GEMINI_API_KEY=<your-key> .venv/bin/python evals/run_agent_evals.py
```

The run enforces:

- free-tier Gemini model only (`GEMINI_MODEL` must be on the allowlist in
  `core/agent/llm_throttle.py`),
- every agent error recorded as a failed row (never silently skipped),
- all output redacted so API keys cannot leak into the report,
- a pass/fail gate (`--min-accuracy`, `--min-recall`, `--max-errors`).

For a credential-free pipeline check (harness self-test, not an evaluation):

```bash
.venv/bin/python evals/run_agent_evals.py --mock-llm
```

Compare results with `evals/baseline_report.md` (legacy single-prompt auditor)
once a live report exists.
